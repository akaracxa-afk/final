# ระบบลงทะเบียนเข้างาน Seminar / Event พร้อมพิมพ์ป้ายชื่อ (เวอร์ชันเบา)

HTML + JavaScript ธรรมดา + Node.js เล็กๆ 1 ไฟล์ **ไม่มี package ที่ต้องดาวน์โหลดเพิ่ม**
ข้อมูลเป็น Mock Data เก็บใน localStorage ของเบราว์เซอร์ รีเฟรชแล้วข้อมูลยังอยู่

## สิ่งที่ต้องติดตั้งก่อน (ทำครั้งเดียว)
1. **Node.js** เวอร์ชัน LTS ดาวน์โหลดที่ https://nodejs.org (กด Next ไปเรื่อยๆ)
2. **VS Code** ดาวน์โหลดที่ https://code.visualstudio.com

## วิธีเปิดใช้งาน
1. คลิกขวาที่ไฟล์ ZIP แล้วเลือก **แตกไฟล์ (Extract All)**
2. เปิด VS Code ไปที่ **File > Open Folder** เลือกโฟลเดอร์ `event-badge-lite`
3. เปิด Terminal ด้วย **Terminal > New Terminal**
4. พิมพ์ `npm install` แล้วกด Enter (เสร็จทันที เพราะไม่มี package)
5. พิมพ์ `npm run dev` แล้วกด Enter
6. เบราว์เซอร์จะเปิดเอง ถ้าไม่เปิด ให้เข้า `http://localhost:3000`

หยุดการทำงานด้วย **Ctrl + C**
(ถ้าพอร์ต 3000 ถูกใช้อยู่ ลอง Windows: `set PORT=3001 && npm run dev` / Mac: `PORT=3001 npm run dev`)

## ฟังก์ชัน
ลงทะเบียน / แก้ไข / ลบ, ค้นหา, สรุปจำนวน, เช็กอิน / ยกเลิกเช็กอิน,
พิมพ์ป้ายชื่อ: เปิดหน้าตัวอย่างก่อนพิมพ์ ตั้งชื่องาน เลือกขนาดป้าย (90×55 มม. / 100×70 มม. / A6) มีบาร์โค้ดรหัสผู้เข้าร่วมบนป้าย แล้วสั่งพิมพ์หรือ Save as PDF,
ปุ่มรีเซ็ตกลับเป็นข้อมูลตัวอย่าง

## ไฟล์
- `server.js` เซิร์ฟเวอร์เปิดไฟล์ในโฟลเดอร์ public
- `public/index.html` หน้าเว็บ
- `public/app.js` ตรรกะทั้งหมด
- `public/mock-data.js` ข้อมูลตัวอย่าง (ชื่อสมมติ)
- `public/style.css` สี/หน้าตา (แก้สีที่ตัวแปรบนสุด)

## ข้อควรรู้
ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่แชร์ข้ามเครื่อง และหายถ้าล้างข้อมูลเบราว์เซอร์

## เคล็ดลับการพิมพ์ป้าย
ในหน้าต่างพิมพ์ของเบราว์เซอร์ ให้เลือกกระดาษ **A4**, สเกล **100%** และติ๊ก **Background graphics** (กราฟิกพื้นหลัง) เพื่อให้แถบสีบนป้ายพิมพ์ออกมา
